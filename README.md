# Evrenin En Yavaş Çay Demleme Makinesi

Bu repository, insanlık tarihinin en büyük bilimsel başarılarından biri olan **Evrenin En Yavaş Çay Demleme Makinesi**'ni barındırmaktadır.

## Nedir Bu?

Bu proje, çay demleme işlemini o kadar yavaş yapar ki, çayınız bitmeden önce evrenin ısı ölümüne şahit olabilirsiniz. Gerçekten çalışan bir Python scripti içerir. Hızlandırmak isterseniz, lütfen başka bir evrende deneyin.

## Nasıl Kullanılır?

```bash
python cay_demle.py
```

Çıktıyı izleyin. Sabırlı olun. Çok sabırlı olun.

## Özellikler

- Gerçekten yavaş
- Gerçekten çalışıyor
- Hiçbir işe yaramaz ama gurur duyar
- Çayınız soğurken felsefe yaparsınız

## Uyarı

Bu makine kullanılırken zamanın doğrusal olduğu varsayılmıştır. Aksi halde sonuçlar öngörülemezdir.
